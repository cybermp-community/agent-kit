# Contributors

CyberMP Community Agent Kit is developed in the open and released under the MIT license. This list records the people whose commits are part of the project, based on the repository history.

- **Nikita Kudiyarov** ([@mo3g666](https://github.com/mo3g666)) — author and maintainer: CLI, MCP server, knowledge base, packaging and releases.
- **Leonardo Neumann** ([@leonardohn](https://github.com/leonardohn)) — live server tools, the bridge library, the `mcp-bridge` resource and the live server documentation.

Contributions of any size are welcome. See [README.md](README.md#contributing) for the checks to run before opening a pull request.
