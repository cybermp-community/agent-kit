# CyberMP Agent Kit

The CLI and Model Context Protocol (MCP) server of the CyberMP Agent Kit, an
offline-first developer toolkit for building CyberMP multiplayer resources.

```bash
npx cybermp-agent-kit init
```

The package ships the CyberMP agent skills, editor rules, templates and the
`mcp-bridge` resource template used by `init --bridge`.

- Repository and full documentation: <https://github.com/mo3g666/cybermp-agent-kit>
- Live server tools: [docs/live-server.md](docs/live-server.md)
- Bridge library: [`cybermp-agent-kit-bridge`](https://www.npmjs.com/package/cybermp-agent-kit-bridge)
