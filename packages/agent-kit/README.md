# CyberMP Community Agent Kit

The CLI and Model Context Protocol (MCP) server of the CyberMP Community Agent
Kit, an offline-first developer toolkit for building CyberMP multiplayer
resources.

```bash
npx @cybermp-community/agent-kit init
```

The binary is named `cybermp-agent-kit`. The package ships the CyberMP agent
skills, editor rules, templates and the `mcp-bridge` resource template used by
`init --bridge`.

- Repository and full documentation: <https://github.com/cybermp-community/agent-kit>
- Live server tools: [docs/live-server.md](docs/live-server.md)
- Bridge library: [`@cybermp-community/agent-kit-bridge`](https://www.npmjs.com/package/@cybermp-community/agent-kit-bridge)
