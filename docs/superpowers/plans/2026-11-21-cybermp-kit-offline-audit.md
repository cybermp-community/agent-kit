# План продолжения аудита CyberMP Agent Kit

> Выполнение по этапам с superpowers:executing-plans. Чекбоксы отражают результаты текущего прохода.

**Цель** — улучшить ответы установленного MCP там, где ошибкой поиска или недостатком сведений можно заняться без игрового стенда.

**Основа** — [спецификация достоверности](../specs/2026-11-20-installed-mcp-and-modding-workflows-design.md) и [аудит базы знаний](../../audits/2026-11-20-knowledge-base.md). Используем существующий индекс Markdown, каталог TweakDB и набор Vitest. Публичные инструменты, аргументы и форматы ID сохраняются.

Запросы старых ID должны сохранять статус `needs-recheck` и подсказку с альтернативой. Сверить запросы по категории и `limit: 1`.

Связать их с закреплённым индексом WolvenKit. Сохранять различие между обнаруженным именем, возможной заменой и поведением на целевой версии игры.

## После прохождения локальных этапов

- Сверить реальные типы записей TweakDB и доступность DLC по выгрузке целевой сборки. Индекс имён WolvenKit подтверждает только имена.
- При доступе к игровому стенду выполнить очередь из аудита. Начать с миникарты на одном клиенте. Проверки собственного архива и зависимостей требуют WolvenKit. Для репликации нужны два клиента.
- Разбор GitHub Actions остаётся отдельной отложенной задачей.
